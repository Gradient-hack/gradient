# Gradient iPhone route flow

A standalone, responsive storyboard for four route-adaptation states:

1. Plan a 25-minute Chinatown to Soho walk.
2. Replan around jazz and music.
3. Reroute from the walker's actual position.
4. Finish with mural context and nearby sushi options.

Open `index.html` directly, or serve this directory with any static file server.
